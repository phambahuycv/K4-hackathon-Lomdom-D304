# Reflection cá nhân

Thư mục này dùng để lưu reflection riêng của từng thành viên trong nhóm.

## Cách dùng
- Mỗi người tạo 1 file riêng trong thư mục này.
- Tên file nên theo mẫu: `reflection/<ten-cua-ban>.md`.
- Nội dung cần trả lời 4 phần chính:
  1. Vai trò và phần mình làm.
  2. AI hỗ trợ thế nào trong quá trình làm việc.
  3. Một case fail hoặc khó khăn của nhóm và bài học rút ra.
  4. Điều mình sẽ cải thiện ở lần sau.
